# Desktop sync troubleshooting

If files are not syncing, check these steps in order:

1. Confirm the device has an active internet connection.
2. Open the CloudBox desktop client and confirm the user is signed in.
3. Check whether the affected folder is selected for sync.
4. Confirm that the local disk has at least 2 GB of free space.
5. Pause and resume sync once.
6. Restart the desktop client.

If duplicate files appear, do not delete them immediately. Check whether two devices edited the file while offline. CloudBox creates a conflict copy to prevent data loss. Ask the user to compare the files, choose the correct version, and rename the final file before deleting the duplicate.

If sync remains blocked after these steps, collect the device operating system, client version, affected folder, and the last successful sync time. Escalate with these details.
