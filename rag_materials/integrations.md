# Supported integrations

CloudBox supports integrations with Slack, Microsoft Teams, Google Workspace, and Zapier. The Slack and Teams integrations can post file activity notifications. Google Workspace can import selected files. Zapier can trigger workflows when a file is created or updated.

The Business plan is required for audit exports. The Team and Business plans support advanced activity notifications. Integrations can be disabled by workspace administrators.

When a user asks whether an integration is supported, answer only from this document unless a current product update is requested. Do not claim that an unsupported integration is available.
