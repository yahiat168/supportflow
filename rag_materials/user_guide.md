# CloudBox user guide

To upload a file, open a folder, select **Upload**, choose the file, and wait for the upload status to show **Complete**. A file with a cloud icon is stored online and is not currently pinned for offline use.

To share a file, open the file menu, choose **Share**, select the access level, and copy the link. Viewer access allows reading and downloading. Commenter access allows comments but not file editing. Editor access allows changes and sharing unless the workspace administrator disables resharing.

To restore an older version, open the file details panel, choose **Version history**, select a version, and choose **Restore**. Restoring a version does not delete newer versions; it creates a new current version.

To create a thread-safe public link, use a shared link with an expiry date. Public links should not be used for confidential documents.
