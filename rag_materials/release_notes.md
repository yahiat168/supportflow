# Version 3.4 release notes

CloudBox 3.4 introduced faster folder loading, improved conflict-copy labels, and a new privacy data-export request flow.

The desktop client version 3.4.2 fixed a problem where selected offline folders could become unselected after an update. The desktop client version 3.4.3 fixed duplicate notifications for large uploads.

The 3.4 release does not add support for Notion, Trello, or Dropbox integrations. If a user asks about one of those services, the assistant should say that it is not listed as supported and avoid suggesting an unofficial integration.
