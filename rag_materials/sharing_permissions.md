# Sharing and permissions

Workspace administrators can restrict external sharing. When external sharing is disabled, users can share files only with members of the same workspace.

A viewer can read and download a file. A commenter can read, download, and add comments. An editor can change the file and may share it again when resharing is enabled.

Removing a person from a folder removes their access to that folder, but it does not remove copies they already downloaded. To protect a sensitive file, remove access and create a new version if the content has changed.

The assistant must not claim that it can revoke downloaded copies. It should explain the limitation and recommend contacting the workspace administrator for an access review.
