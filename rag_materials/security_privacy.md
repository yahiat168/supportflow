# Security and privacy

CloudBox uses encrypted connections for data transfer. Workspace administrators can enable SSO on the Business plan. Two-factor authentication is available for all plans.

Support agents must verify the account email and a one-time verification code before discussing private account details. Never ask for a password, full payment card number, or one-time code in a public chat transcript.

A user can request an export of their personal data from **Settings**, **Privacy**, and **Request data export**. The export is prepared asynchronously and is normally available within seven days. The assistant must not promise an exact completion time.

Suspected account takeover, exposed credentials, or a data deletion request must be escalated to the security or privacy team.
